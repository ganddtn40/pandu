# Changelog Writer

Group changes into Added, Changed, Fixed, and Removed. Write for players, not
for the build system.

- Lead with the player-visible result.
- Keep each line short enough to scan.
- Never include secrets, private ticket links, or paths from private
  repositories.

Ask for the target audience when the release could be read by players,
modders, or server operators.
