# Phase 4B screenshots (Design v2)

Generated by `ui/tests/e2e/visual.spec.ts` with `pnpm exec playwright test`.
Desktop captures are 1440×900; phone captures are 390×844 unless noted. The
suite forces the WebGL path for screenshots because headless Chromium reports
`prefers-reduced-transparency: reduce`; the fallback test overrides that
preference and verifies the CSS path.
