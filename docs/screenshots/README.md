# Screenshots

These images document the shipped UI and the installers. Most directories are
generated by the Playwright suites and can be regenerated at any time; the
Phase 11 captures come from a real Windows release build, and the Phase 11b
captures come from an Android 17 emulator.

## Phase 11b

| File | What it shows | Source |
| --- | --- | --- |
| `phase11b/01-pair-form.png` | The companion's manual pairing form on first launch | Debug APK on `Medium_Phone_API_37.0` (Android 17, 1080×2400) |
| `phase11b/02-pair-waiting.png` | Waiting for the host to confirm the four-digit code | Same emulator |
| `phase11b/03-paired-dashboard.png` | A paired Status-only device with an empty inbox | Same emulator |
| `phase11b/04-guard-inbox.png` | A live high-risk approval waiting in the inbox | Same emulator |
| `phase11b/05-notification-channels.png` | Android's notification settings showing the four Pandu channels | Same emulator |

The companion ran against a disposable `PANDU_HOME` on loopback, so no
developer data appears in the frames. The high-risk approval used a real
`rm -rf /` request paused by the guard. The scanner overlay and the
BiometricPrompt were exercised but are not in this set: the system prompt is a
secure window, so screenshots of it are black.

### Not captured

| Shot | Why | How to capture |
| --- | --- | --- |
| Tray menu | A native tray menu is outside the WebView; screen capture of the open menu is unreliable on a headless runner | Install the NSIS build, open the tray menu, and capture the screen on a desktop session |
| MSI installer | The MSI is per-machine and needs an administrator prompt | Run the MSI in a clean VM and capture the UAC and WiX pages |
| Android on a physical phone | No physical phone was available; the emulator covers API 37 only | Install the APK on a phone and capture pairing, notifications, and battery-optimisation screens |
| Successful QR decode | The emulator camera had no real QR code; permission, overlay, and cancel were verified | Display a real pairing QR and capture the decoded form |
| PWA install prompt | Needs the daemon served over HTTPS (Tailscale) and a browser that offers installation | Follow `docs/install/pwa.md` and capture the install prompt and the standalone window |

Do not add mockups or browser-only renders for the missing rows. An absent
screenshot is better than one that implies an install or device path that was
never tested.
