# Установка Pandu

Pandu — локальный самописец полётов и диспетчерская вышка для агентов
программирования с ИИ. Он работает на вашем компьютере, записывает действия
агентов и хранит каждый полёт, настройку и подключённое устройство на вашей
машине. Аккаунта, облачной синхронизации и телеметрии нет.

Это руководство охватывает приложение для Windows, компаньон для Android,
устанавливаемое веб-приложение (PWA) и инструмент командной строки. Все команды
можно безопасно копировать и вставлять. Английское руководство [`en.md`](en.md)
служит полным справочником при расхождениях.

## Что понадобится

| Компонент | Требования |
| --- | --- |
| Приложение Windows | Windows 10 или 11, 64 бита. Microsoft Edge WebView2 (входит в современную Windows; установщик может его скачать). |
| Компаньон Android | Android 10 или новее. Сетевой путь от телефона до компьютера: `tailscale serve` или другой HTTPS-туннель. |
| PWA | Актуальный Chrome, Edge, Safari или Firefox. Страница должна открываться по HTTPS. |
| Компьютер с Pandu | Windows, macOS или Linux для демона и CLI. Настольная оболочка в этом выпуске только для Windows. |

Для рекомендуемого установщика Windows **не** нужны права администратора, и
аккаунт нигде **не** требуется.

## Приложение для Windows

### Выберите файл

Скачивайте файлы с одной и той же страницы выпуска на GitHub. Не смешивайте
файлы из разных выпусков.

| Файл | Когда использовать |
| --- | --- |
| `Pandu_0.2.0_x64-setup.exe` | **Рекомендуется.** Установка для текущего пользователя, без запроса прав администратора. |
| `Pandu_0.2.0_x64_en-US.msi` | Вы развёртываете ПО в организации. Установка для всей машины; нужны права администратора. |
| `pandu-0.2.0-x86_64-pc-windows-msvc-portable.zip` | Установщик не нужен. Распакуйте и запустите. |

Номер версии в имени файла меняется с каждым выпуском. Используйте последний
стабильный выпуск, если в примечаниях не сказано иное.

### Сначала проверьте загрузку

В каждом выпуске есть файл `SHA256SUMS`. Скачайте его в ту же папку, что и
установщик, затем откройте PowerShell в этой папке:

```powershell
Get-FileHash .\Pandu_0.2.0_x64-setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS | Select-String 'Pandu_0.2.0_x64-setup.exe'
```

Хеши должны совпасть полностью. Если нет, удалите файл и скачайте снова. Не
запускайте файл с несовпадающим хешем, даже если страница выглядит официальной.

### Установка (рекомендуется, для пользователя)

1. Дважды щёлкните `Pandu_0.2.0_x64-setup.exe`.
2. Если Windows показывает **Windows protected your PC**, выберите **More
   info**, затем **Run anyway**. Делайте так только если файл получен с
   официальной страницы выпуска и его SHA-256 совпал на предыдущем шаге.
   Релизные сборки не подписаны, если в примечаниях не указан сертификат
   Authenticode.
3. Следуйте указаниям установщика. Он устанавливает приложение для вашей
   учётной записи и не требует прав администратора.
4. Если WebView2 отсутствует, установщик скачает Evergreen bootstrapper
   Microsoft. Это единственный раз, когда установщику нужен интернет.
5. Запустите Pandu из меню «Пуск».

Установщик не добавляет запись в автозагрузку. Автозапуск **по умолчанию
выключен**.

### Первый запуск

Открывается окно Pandu и запускается локальный демон. Демон слушает свободный
порт loopback, поэтому доступен только с вашего компьютера. Интерфейс встроен в
приложение; Pandu не загружает удалённый веб-контент.

- **Закрытие окна не завершает работу.** Pandu остаётся в области уведомлений,
  чтобы продолжать запись. Откройте его снова через значок в трее.
- **Завершение — явное действие.** Щёлкните значок в трее правой кнопкой и
  выберите **Quit Pandu**. После завершения агенты не записываются, пока вы не
  запустите Pandu снова.
- **Ваши данные** находятся в `%USERPROFILE%\.pandu`. База данных —
  `%USERPROFILE%\.pandu\v2\pandu.db`; настройки, снимки и резервные копии — в
  том же дереве.

### Удаление

1. Завершите Pandu через трей.
2. Откройте **Settings > Apps > Installed apps**, найдите **Pandu** и выберите
   **Uninstall**.
3. Установщик спросит, удалять ли `%USERPROFILE%\.pandu`. По умолчанию —
   **No**. Выберите **No**, чтобы сохранить полёты, настройки, снимки,
   резервные копии и подключённые устройства. Выбирайте **Yes**, только если
   хотите удалить их навсегда.

Полная очистка описана в [`uninstall.md`](uninstall.md).

## Компаньон для Android

Компаньон — небольшой ограниченный дашборд для телефона. Он может смотреть
полёты и отвечать на запросы подтверждения, но не может запускать агентов или
менять настройки. Он необязателен.

**Экспериментально:** компаньон Android проверен на эмуляторе, но ещё не на
реальном телефоне. APK не прикладывается к выпускам, пока не будет
зафиксирована проверка на телефоне; если хотите протестировать, соберите его из
исходников.

Кратко:

1. На компьютере откройте **Settings > Remote access** и включите удалённый
   доступ. Выберите режим Tailscale и выполните команду `tailscale serve`,
   которую покажет Pandu.
2. Соберите APK из исходников (экспериментально); см.
   [`android.md`](android.md).
3. Разрешите браузеру или файловому менеджеру установку неизвестных приложений
   и откройте APK.
4. Откройте Pandu на телефоне и отсканируйте QR-код сопряжения с компьютера.
5. Подтвердите устройство на компьютере. Новые устройства начинают только с
   права **Status**.

Полное руководство, включая разрешения, настройки батареи, каналы уведомлений и
проверку `apksigner`, находится в [`android.md`](android.md).

## Устанавливаемое веб-приложение (PWA)

PWA — та же удалённая панель, установленная из браузера. Нужен HTTPS-адрес,
ведущий к вашему компьютеру, обычно через `tailscale serve`.

1. Включите удалённый доступ на компьютере и запустите `tailscale serve`.
2. Откройте HTTPS-адрес на телефоне или другом компьютере.
3. В меню браузера выберите **Install app** или **Add to Home Screen**.
4. Сопрягите устройство по коду, показанному на компьютере.

Полное руководство с правилами кеширования и ограничениями — в
[`pwa.md`](pwa.md).

## Инструмент командной строки

CLI `pandu` отделён от настольного приложения. Установите его, если хотите
запускать демон самостоятельно, использовать `pandu run -- <agent>` или
запускать диагностику.

1. Скачайте `pandu-cli-x86_64-pc-windows-msvc.zip` и `SHA256SUMS`.
2. Проверьте архив через `Get-FileHash`, как показано выше.
3. Распакуйте. В архиве есть папка `pandu-cli-x86_64-pc-windows-msvc` с
   `pandu.exe`.
4. Добавьте эту папку в `PATH` или запускайте `pandu.exe` по полному пути.

В выпуск также входит `pandu-cli-installer.ps1`, устанавливающий CLI для
текущего пользователя. Прочитайте скрипт перед запуском, если хотите точно
знать, куда он пишет.

Полезные первые команды:

```powershell
pandu doctor
pandu serve
pandu pair
```

`pandu doctor` проверяет базу данных, адаптеры, наблюдатель за журналами и
запущенный демон. Он выводит только локальную информацию. `pandu pair`
показывает короткоживущий код сопряжения и удалённый URL для телефона.

## Решение проблем

Если что-то не работает, прочитайте [`troubleshooting.md`](troubleshooting.md).
Там описаны SmartScreen, WebView2, конфликты портов, запросы брандмауэра, сбои
сопряжения, проблемы с уведомлениями и сброс Pandu без потери данных.

## Конфиденциальность в одном абзаце

Pandu записывает данные локально. Настольное приложение общается только с
демоном на loopback. Удалённый доступ по умолчанию выключен и включается только
с компьютера. Проверка обновлений — один HTTPS-запрос к GitHub не чаще раза в
24 часа, её можно отключить. Телеметрии, облачной синхронизации и фоновой
загрузки нет. Полное заявление — в [`privacy.md`](../privacy.md).
