# Pandu のインストール

Pandu は、AI コーディングエージェントのためのローカルフライトレコーダー兼
コントロールタワーです。お使いのコンピューター上で動作し、エージェントの
行動を記録します。フライト、設定、ペアリングした端末はすべて手元のマシンに
保存されます。アカウント、クラウド同期、テレメトリーはありません。

このガイドでは、Windows デスクトップアプリ、Android コンパニオン、インストール
可能な Web アプリ（PWA）を説明します。コマンドはそのままコピーできます。

## 必要なもの

| 部分 | 要件 |
| --- | --- |
| Windows アプリ | Windows 10 または 11（64 ビット）。Microsoft Edge WebView2（最新の Windows には同梱。インストーラーがダウンロード可能）。 |
| Android コンパニオン | Android 10 以降。スマートフォンからコンピューターへのネットワーク経路（`tailscale serve` などの HTTPS トンネル）。 |
| PWA | 最新の Chrome、Edge、Safari、Firefox。ページは HTTPS で配信されている必要があります。 |
| Pandu を動かすコンピューター | デーモンと CLI は Windows、macOS、Linux。デスクトップシェルはこのリリースでは Windows のみです。 |

推奨の Windows インストーラーに管理者権限は**不要**で、アカウントも**不要**です。

## Windows デスクトップアプリ

### ファイルの選択

同じ GitHub リリースページからダウンロードしてください。異なるリリースの
ファイルを混ぜないでください。

| ファイル | 使う場面 |
| --- | --- |
| `Pandu_0.2.0_x64-setup.exe` | **推奨。** ユーザー単位のインストール。管理者の確認は出ません。 |
| `Pandu_0.2.0_x64_en-US.msi` | 組織でソフトウェアを配布する場合。コンピューター単位のインストールで、管理者権限が必要です。 |
| `pandu-0.2.0-x86_64-pc-windows-msvc-portable.zip` | インストーラーを使いたくない場合。展開して実行します。 |

バージョン番号はリリースごとに変わります。特別な記載がなければ最新の安定版を
使ってください。

### 先にダウンロードを検証する

各リリースには `SHA256SUMS` が含まれます。インストーラーと同じフォルダーに
ダウンロードし、そのフォルダーで PowerShell を開きます。

```powershell
Get-FileHash .\Pandu_0.2.0_x64-setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS | Select-String 'Pandu_0.2.0_x64-setup.exe'
```

2 つのハッシュが完全に一致する必要があります。一致しない場合はファイルを
削除して再ダウンロードしてください。ページが公式に見えても、ハッシュが
一致しないファイルは実行しないでください。

### インストール（推奨・ユーザー単位）

1. `Pandu_0.2.0_x64-setup.exe` をダブルクリックします。
2. **Windows protected your PC** と表示されたら、**More info** を選び、
   **Run anyway** をクリックします。公式リリースページから取得し、SHA-256 が
   一致した場合だけ行ってください。リリースビルドは、リリースノートに
   Authenticode 証明書の記載がない限り署名されていません。
3. インストーラーの指示に従います。自分のアカウント用にインストールされ、
   管理者権限は要求されません。
4. WebView2 がない場合、インストーラーが Microsoft の Evergreen
   ブートストラップをダウンロードします。インターネットが必要なのはこの
   ときだけです。
5. スタートメニューから Pandu を起動します。

インストーラーはスタートアップ項目を追加しません。自動起動は**既定で
オフ**です。

### 初回起動

Pandu のウィンドウが開き、ローカルデーモンが起動します。デーモンは空いて
いるループバックポートで待ち受けるため、自分のコンピューターからしか
アクセスできません。UI はアプリに同梱されており、Pandu はリモートの Web
コンテンツを読み込みません。

- **ウィンドウを閉じても終了しません。** Pandu は通知領域に残り、記録を
  続けます。トレイアイコンから再度開けます。
- **終了は明示的です。** トレイアイコンを右クリックし、**Quit Pandu** を
  選びます。
- **自動起動。** サインイン時に起動したい場合は、トレイメニューの
  **Start Pandu with Windows** をオンにします。オフにすると解除されます。
- **データの場所**は `%USERPROFILE%\.pandu` です。データベースは
  `%USERPROFILE%\.pandu\v2\pandu.db` にあり、設定、スナップショット、
  バックアップも同じツリーにあります。

### ディープリンク

Pandu は `pandu://` URL スキームを登録します。
`pandu://flights/<flight-id>` のようなリンクで、そのフライトをデスクトップ
アプリで開きます。リンクは検証され、未知のパスや安全でないセグメントは
無視されます。Pandu がリンクから任意のリモートページを開くことはありません。

### 管理された展開向けの MSI

MSI は、グループポリシー、Intune、その他のパッケージマネージャーを既に
使っている IT 部門向けの、コンピューター単位のインストールです。

- 管理者権限が必要です。
- コンピューターのすべてのユーザーにインストールされます。
- ユーザーデータは各ユーザーの `%USERPROFILE%\.pandu` に残ります。
- NSIS のデータ削除確認は MSI には適用されません。MSI をアンインストール
  した後、フライトと設定も消したい場合だけ `%USERPROFILE%\.pandu` を手動で
  削除してください。

### ポータブル版

1. `pandu-0.2.0-x86_64-pc-windows-msvc-portable.zip` を自分のフォルダーに
   展開します。
2. `Pandu.exe` を実行します。インストーラーも管理者権限も不要です。
3. WebView2 がインストールされている必要があります。最新の Windows には
   同梱されています。Pandu が起動しない場合は、Microsoft の Evergreen
   Runtime（<https://developer.microsoft.com/microsoft-edge/webview2/>）を
   インストールしてください。
4. 削除するには、トレイから終了し、フォルダーを削除します。データも消す
   場合だけ `%USERPROFILE%\.pandu` を削除してください。

### アンインストール

1. トレイから Pandu を終了します。
2. **設定 > アプリ > インストールされているアプリ** を開き、**Pandu** を
   選んで **アンインストール** をクリックします。
3. `%USERPROFILE%\.pandu` を削除するか尋ねられます。既定は **いいえ** です。
   **いいえ** を選ぶと、フライト、設定、スナップショット、バックアップ、
   ペアリング済み端末が残ります。完全に消したい場合だけ **はい** を選んで
   ください。
4. サイレントアンインストールでは常にデータが保持されます。

## Android コンパニオン

コンパニオンはスマートフォン向けの小さな限定ダッシュボードです。フライトの
閲覧と承認リクエストへの回答はできますが、エージェントの起動や設定の変更は
できません。任意の機能です。

**実験的:** Android コンパニオンはエミュレーターと実機でまだ検証されていません。
検証が完了するまで APK はリリースに添付されません。試す場合はソースから
ビルドしてください。

概要:

1. コンピューターで **Settings > Remote access** を開き、リモートアクセスを
   有効にします。Tailscale モードを選び、Pandu が表示する
   `tailscale serve` コマンドを実行します。
2. ソースから APK をビルドします（実験的）。[android.md](android.md) を参照
   してください。
3. ブラウザーまたはファイルマネージャーに「提供元不明のアプリ」のインストール
   を許可し、APK を開きます。
4. スマートフォンで Pandu を開き、コンピューターの QR コードをスキャン
   します。
5. コンピューターで端末を承認します。新しい端末は **Status** のみから
   始まります。

権限、バッテリー設定、通知チャンネル、`apksigner` による検証を含む詳細は
[android.md](android.md) を参照してください。

## Web アプリ（PWA）

PWA は同じリモートダッシュボードをブラウザーからインストールしたものです。
通常は `tailscale serve` による、コンピューターに届く HTTPS URL が必要です。

概要:

1. コンピューターでリモートアクセスを有効にし、`tailscale serve` を開始
   します。
2. スマートフォンまたは別のコンピューターで HTTPS URL を開きます。
3. ブラウザーのメニューから **アプリをインストール** または
   **ホーム画面に追加** を選びます。
4. コンピューターに表示されたコードで端末をペアリングします。

キャッシュの規則と制限を含む詳細は [pwa.md](pwa.md) を参照してください。

## コマンドラインツール

`pandu` CLI はデスクトップアプリとは別です。デーモンを自分で起動する、
`pandu run -- <agent>` を使う、診断を実行する場合にインストールします。

1. `pandu-cli-x86_64-pc-windows-msvc.zip` と `SHA256SUMS` をダウンロードします。
2. 上記と同様に `Get-FileHash` でアーカイブを検証します。
3. 展開します。`pandu.exe` はアーカイブの直下にあります。
4. 展開先のフォルダーを `PATH` に追加するか、フルパスで `pandu.exe` を実行します。

リリースには `pandu-cli-installer.ps1` も含まれます。現在のユーザー用に CLI
をインストールします。書き込み先を正確に知りたい場合は、実行前にスクリプトを
読んでください。

便利な最初のコマンド:

```powershell
pandu doctor
pandu serve
pandu pair
```

`pandu doctor` はデータベース、アダプター、ログ監視、実行中のデーモンを
確認します。`pandu pair` は短時間有効なペアリングコードと、スマートフォン用の
リモート URL を表示します。

## トラブルシューティング

問題が起きた場合は [troubleshooting.md](troubleshooting.md) を読んでください。
SmartScreen、WebView2、ポート競合、ファイアウォールの確認、ペアリングの失敗、
通知の問題、データを失わずに Pandu をリセットする方法を扱っています。

### クイックまとめ

- **SmartScreen:** SHA-256 を確認し、公式リリースのファイルだけ
  **More info > Run anyway** を選びます。
- **WebView2 がない:** Microsoft の Evergreen Runtime をインストールし、
  Pandu を再起動します。
- **APK をインストールできない:** 使用するブラウザーまたはファイル
  マネージャーにだけ **提供元不明のアプリ** を許可し、再試行します。
- **Android の通知が遅い:** WorkManager は最大 15 分間隔で確認します。
  バッテリーを **Unrestricted** にし、必要なチャンネルをミュートしないで
  ください。
- **PWA をインストールできない:** ページが HTTPS であることを確認し、
  Chrome、Edge、Safari のいずれかを使います。

## プライバシー（要約）

Pandu はローカルに記録します。デスクトップアプリはループバックのデーモンと
だけ通信します。リモートアクセスは既定でオフで、コンピューターからしか
有効にできません。更新確認は GitHub への HTTPS リクエスト 1 回だけで、
24 時間に最大 1 回、無効にできます。テレメトリー、クラウド同期、バック
グラウンドアップロードはありません。完全な説明は
[privacy.md](../privacy.md) を参照してください。
