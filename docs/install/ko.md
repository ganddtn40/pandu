# Pandu 설치

Pandu는 AI 코딩 에이전트를 위한 로컬 비행 기록 장치이자 관제탑입니다. 사용자의
컴퓨터에서 실행되며 에이전트가 하는 일을 기록하고, 모든 비행과 설정과 페어링된
기기를 사용자의 기기에 보관합니다. 계정도, 클라우드 동기화도, 텔레메트리도
없습니다.

이 안내서는 Windows 데스크톱 앱, Android 컴패니언, 설치형 웹 앱(PWA), 명령줄
도구를 다룹니다. 모든 명령은 복사해 붙여 넣어도 안전합니다. 내용이 다를 때는
영어 안내서 [`en.md`](en.md)가 기준입니다.

## 필요한 것

| 구성 요소 | 요구 사항 |
| --- | --- |
| Windows 앱 | Windows 10 또는 11, 64비트. Microsoft Edge WebView2(최신 Windows에 포함, 설치 프로그램이 내려받을 수 있음). |
| Android 컴패니언 | Android 10 이상. 휴대폰에서 컴퓨터로 가는 네트워크 경로: `tailscale serve` 또는 다른 HTTPS 터널. |
| PWA | 최신 Chrome, Edge, Safari 또는 Firefox. 페이지가 HTTPS로 제공되어야 합니다. |
| Pandu를 실행할 컴퓨터 | 데몬과 CLI용 Windows, macOS 또는 Linux. 이번 릴리스의 데스크톱 셸은 Windows 전용입니다. |

권장 Windows 설치 프로그램에는 관리자 권한이 필요 없고, 어디에도 계정을 만들
필요가 없습니다.

## Windows 데스크톱 앱

### 파일 선택

같은 GitHub 릴리스 페이지에서 파일을 내려받으세요. 서로 다른 릴리스의 파일을
섞지 마세요.

| 파일 | 사용할 때 |
| --- | --- |
| `Pandu_0.2.0_x64-setup.exe` | **권장.** 사용자별 설치, 관리자 권한 요청 없음. |
| `Pandu_0.2.0_x64_en-US.msi` | 조직에 소프트웨어를 배포할 때. 컴퓨터 전체 설치, 관리자 권한 필요. |
| `pandu-0.2.0-x86_64-pc-windows-msvc-portable.zip` | 설치 프로그램 없이 쓰고 싶을 때. 압축을 풀고 실행하세요. |

파일 이름의 버전 번호는 릴리스마다 바뀝니다. 릴리스 노트에 다른 안내가 없으면
최신 안정 릴리스를 사용하세요.

### 먼저 다운로드 확인

모든 릴리스에는 `SHA256SUMS` 파일이 있습니다. 설치 프로그램과 같은 폴더에
내려받은 뒤 그 폴더에서 PowerShell을 여세요:

```powershell
Get-FileHash .\Pandu_0.2.0_x64-setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS | Select-String 'Pandu_0.2.0_x64-setup.exe'
```

두 해시가 정확히 같아야 합니다. 다르면 파일을 삭제하고 다시 내려받으세요. 페이지가
공식처럼 보여도 해시가 맞지 않는 파일은 실행하지 마세요.

### 설치(권장, 사용자별)

1. `Pandu_0.2.0_x64-setup.exe`를 두 번 클릭합니다.
2. Windows가 **Windows protected your PC**를 표시하면 **More info**를 누른 뒤
   **Run anyway**를 선택합니다. 파일이 공식 릴리스 페이지에서 왔고 이전 단계에서
   SHA-256이 일치할 때만 이렇게 하세요. 릴리스 노트에 Authenticode 인증서를
   사용했다고 적혀 있지 않으면 릴리스 빌드는 서명되지 않습니다.
3. 설치 프로그램을 따릅니다. 사용자 계정에 설치하며 관리자 권한을 요구하지
   않습니다.
4. WebView2가 없으면 설치 프로그램이 Microsoft Evergreen 부트스트래퍼를
   내려받습니다. 설치 프로그램이 인터넷을 쓰는 유일한 순간입니다.
5. 시작 메뉴에서 Pandu를 실행합니다.

설치 프로그램은 시작 프로그램 항목을 추가하지 않습니다. 자동 시작은
**기본적으로 꺼져** 있습니다.

### 첫 실행

Pandu 창이 열리고 로컬 데몬이 시작됩니다. 데몬은 사용 가능한 루프백 포트에서
수신하므로 사용자의 컴퓨터에서만 접근할 수 있습니다. UI는 앱 안에 포함되어
있으며 Pandu는 원격 웹 콘텐츠를 불러오지 않습니다.

- **창을 닫아도 종료되지 않습니다.** Pandu는 계속 기록하기 위해 알림 영역에서
  실행됩니다. 트레이 아이콘으로 다시 열 수 있습니다.
- **종료는 명시적입니다.** 트레이 아이콘을 마우스 오른쪽 버튼으로 클릭하고
  **Quit Pandu**를 선택합니다. 종료하면 다시 시작할 때까지 에이전트가 기록되지
  않습니다.
- **데이터**는 `%USERPROFILE%\.pandu`에 있습니다. 데이터베이스는
  `%USERPROFILE%\.pandu\v2\pandu.db`이고 설정, 스냅샷, 백업도 같은 트리에
  있습니다.

### 제거

1. 트레이에서 Pandu를 종료합니다.
2. **Settings > Apps > Installed apps**를 열고 **Pandu**를 찾아
   **Uninstall**을 선택합니다.
3. 제거 프로그램이 `%USERPROFILE%\.pandu`를 삭제할지 묻습니다. 기본값은
   **No**입니다. 비행, 설정, 스냅샷, 백업, 페어링된 기기를 유지하려면 **No**를
   선택하세요. 영구 삭제하려는 경우에만 **Yes**를 선택하세요.

전체 정리 방법은 [`uninstall.md`](uninstall.md)에 있습니다.

## Android 컴패니언

컴패니언은 휴대폰용의 작고 범위가 제한된 대시보드입니다. 비행을 보고 승인
요청에 답할 수 있지만 에이전트를 시작하거나 설정을 바꿀 수는 없습니다. 선택
사항입니다.

**실험적:** Android 컴패니언은 에뮬레이터에서 검증했지만 아직 실제 휴대폰에서는
검증하지 않았습니다. 휴대폰 검증이 기록될 때까지 APK는 릴리스에 첨부되지
않습니다. 시험하려면 소스에서 빌드하세요.

요약:

1. 컴퓨터에서 **Settings > Remote access**를 열고 원격 접속을 켭니다.
   Tailscale 모드를 선택하고 Pandu가 보여 주는 `tailscale serve` 명령을
   실행합니다.
2. 소스에서 APK를 빌드합니다(실험적). [`android.md`](android.md)를 참고하세요.
3. 브라우저나 파일 관리자가 알 수 없는 앱을 설치하도록 허용한 뒤 APK를
   엽니다.
4. 휴대폰에서 Pandu를 열고 컴퓨터에 표시된 페어링 QR 코드를 스캔합니다.
5. 컴퓨터에서 기기를 승인합니다. 새 기기는 **Status** 권한으로 시작합니다.

권한, 배터리 설정, 알림 채널, `apksigner` 검증을 포함한 전체 안내는
[`android.md`](android.md)에 있습니다.

## 설치형 웹 앱(PWA)

PWA는 같은 원격 대시보드를 브라우저에서 설치한 것입니다. 보통
`tailscale serve`로 만든, 컴퓨터에 닿는 HTTPS URL이 필요합니다.

1. 컴퓨터에서 원격 접속을 켜고 `tailscale serve`를 시작합니다.
2. 휴대폰이나 다른 컴퓨터에서 HTTPS URL을 엽니다.
3. 브라우저 메뉴에서 **Install app** 또는 **Add to Home Screen**을 선택합니다.
4. 컴퓨터에 표시된 코드로 기기를 페어링합니다.

캐시 규칙과 제한을 포함한 전체 안내는 [`pwa.md`](pwa.md)에 있습니다.

## 명령줄 도구

`pandu` CLI는 데스크톱 앱과 별개입니다. 데몬을 직접 실행하거나
`pandu run -- <agent>`를 쓰거나 진단을 실행하려면 설치하세요.

1. `pandu-cli-x86_64-pc-windows-msvc.zip`과 `SHA256SUMS`를 내려받습니다.
2. 위와 같이 `Get-FileHash`로 압축 파일을 확인합니다.
3. 압축을 풉니다. ZIP 안의 `pandu-cli-x86_64-pc-windows-msvc` 폴더에
   `pandu.exe`가 있습니다.
4. 그 폴더를 `PATH`에 추가하거나 `pandu.exe`를 전체 경로로 실행합니다.

릴리스에는 현재 사용자용 CLI를 설치하는 `pandu-cli-installer.ps1`도 포함됩니다.
정확히 어디에 쓰는지 알고 싶다면 실행 전에 스크립트를 읽어 보세요.

유용한 첫 명령:

```powershell
pandu doctor
pandu serve
pandu pair
```

`pandu doctor`는 데이터베이스, 어댑터, 로그 감시자, 실행 중인 데몬을 확인합니다.
로컬 정보만 출력합니다. `pandu pair`는 짧게 유효한 페어링 코드와 휴대폰에서 쓸
원격 URL을 출력합니다.

## 문제 해결

무언가 작동하지 않으면 [`troubleshooting.md`](troubleshooting.md)를 읽으세요.
SmartScreen, WebView2, 포트 충돌, 방화벽 알림, 페어링 실패, 알림 문제, 데이터를
잃지 않고 Pandu를 초기화하는 방법을 다룹니다.

## 한 문단으로 보는 개인정보

Pandu는 로컬에 기록합니다. 데스크톱 앱은 루프백의 데몬과만 통신합니다. 원격
접속은 기본적으로 꺼져 있으며 컴퓨터에서만 켤 수 있습니다. 업데이트 확인은
최대 24시간에 한 번 GitHub에 보내는 HTTPS 요청 하나이며 끌 수 있습니다.
텔레메트리, 클라우드 동기화, 백그라운드 업로드는 없습니다. 전체 내용은
[`privacy.md`](../privacy.md)에 있습니다.
