# Pandu इंस्टॉल करें

Pandu AI कोडिंग एजेंट्स के लिए एक स्थानीय फ़्लाइट रिकॉर्डर और कंट्रोल टावर है।
यह आपके कंप्यूटर पर चलता है, आपके एजेंट्स क्या करते हैं उसे रिकॉर्ड करता है, और
हर फ़्लाइट, सेटिंग और जोड़ा गया डिवाइस आपकी मशीन पर रखता है। कोई अकाउंट नहीं,
कोई क्लाउड सिंक नहीं, कोई टेलीमेट्री नहीं।

यह गाइड Windows डेस्कटॉप ऐप, Android कंपेनियन, इंस्टॉल करने योग्य वेब ऐप
(PWA), और कमांड-लाइन टूल को कवर करती है। सभी कमांड कॉपी-पेस्ट करने के लिए
सुरक्षित हैं। किसी भी अंतर की स्थिति में अंग्रेज़ी गाइड [`en.md`](en.md) पूर्ण
संदर्भ है।

## आपको क्या चाहिए

| भाग | आवश्यकताएँ |
| --- | --- |
| Windows ऐप | Windows 10 या 11, 64-बिट। Microsoft Edge WebView2 (आधुनिक Windows में शामिल; इंस्टॉलर इसे डाउनलोड कर सकता है)। |
| Android कंपेनियन | Android 10 या नया। फ़ोन से कंप्यूटर तक नेटवर्क पथ: `tailscale serve` या कोई अन्य HTTPS टनल। |
| PWA | कोई वर्तमान Chrome, Edge, Safari या Firefox। पेज HTTPS पर परोसा जाना चाहिए। |
| Pandu चलाने वाला कंप्यूटर | डेमॉन और CLI के लिए Windows, macOS या Linux। इस रिलीज़ में डेस्कटॉप शेल केवल Windows के लिए है। |

अनुशंसित Windows इंस्टॉलर के लिए आपको एडमिनिस्ट्रेटर अधिकार नहीं चाहिए, और
कहीं भी अकाउंट की ज़रूरत नहीं है।

## Windows डेस्कटॉप ऐप

### फ़ाइल चुनें

ये फ़ाइलें उसी GitHub रिलीज़ पेज से डाउनलोड करें। अलग-अलग रिलीज़ की फ़ाइलें
मिलाएँ नहीं।

| फ़ाइल | कब इस्तेमाल करें |
| --- | --- |
| `Pandu_0.2.0_x64-setup.exe` | **अनुशंसित।** प्रति-उपयोगकर्ता इंस्टॉल, एडमिनिस्ट्रेटर प्रॉम्प्ट नहीं। |
| `Pandu_0.2.0_x64_en-US.msi` | आप किसी संस्था के लिए सॉफ़्टवेयर डिप्लॉय करते हैं। प्रति-मशीन इंस्टॉल; एडमिनिस्ट्रेटर अधिकार चाहिए। |
| `pandu-0.2.0-x86_64-pc-windows-msvc-portable.zip` | आप इंस्टॉलर नहीं चाहते। एक्सट्रैक्ट करें और चलाएँ। |

फ़ाइल नाम में संस्करण हर रिलीज़ के साथ बदलता है। जब तक रिलीज़ नोट्स कुछ और न
कहें, नवीनतम स्थिर रिलीज़ इस्तेमाल करें।

### पहले डाउनलोड जाँचें

हर रिलीज़ में `SHA256SUMS` नाम की फ़ाइल होती है। इसे इंस्टॉलर के साथ उसी फ़ोल्डर
में डाउनलोड करें, फिर वहाँ PowerShell खोलें:

```powershell
Get-FileHash .\Pandu_0.2.0_x64-setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS | Select-String 'Pandu_0.2.0_x64-setup.exe'
```

दोनों हैश बिल्कुल मेल खाने चाहिए। अगर नहीं मिलते, फ़ाइल हटाएँ और दोबारा
डाउनलोड करें। जिस फ़ाइल का हैश न मिले, उसे न चलाएँ, भले ही पेज आधिकारिक लगे।

### इंस्टॉल करें (अनुशंसित, प्रति-उपयोगकर्ता)

1. `Pandu_0.2.0_x64-setup.exe` पर डबल-क्लिक करें।
2. अगर Windows **Windows protected your PC** दिखाए, तो **More info** और फिर
   **Run anyway** चुनें। ऐसा केवल तब करें जब फ़ाइल आधिकारिक रिलीज़ पेज से आई हो
   और पिछले चरण में उसका SHA-256 मेल खाया हो। जब तक रिलीज़ नोट्स Authenticode
   प्रमाणपत्र का उल्लेख न करें, रिलीज़ बिल्ड अहस्ताक्षरित हैं।
3. इंस्टॉलर का पालन करें। यह आपके उपयोगकर्ता खाते के लिए इंस्टॉल करता है और
   एडमिनिस्ट्रेटर अधिकार नहीं माँगता।
4. अगर WebView2 नहीं है, तो इंस्टॉलर Microsoft का Evergreen bootstrapper
   डाउनलोड करता है। केवल इसी समय इंस्टॉलर को इंटरनेट चाहिए।
5. Start मेन्यू से Pandu शुरू करें।

इंस्टॉलर स्टार्टअप एंट्री नहीं जोड़ता। ऑटोस्टार्ट **डिफ़ॉल्ट रूप से बंद** है।

### पहला रन

Pandu विंडो खुलती है और स्थानीय डेमॉन शुरू होता है। डेमॉन एक मुक्त लूपबैक पोर्ट
पर सुनता है, इसलिए यह केवल आपके कंप्यूटर से पहुँचने योग्य है। UI ऐप के अंदर
शामिल है; Pandu दूर का वेब कंटेंट लोड नहीं करता।

- **विंडो बंद करने से ऐप बंद नहीं होता।** Pandu नोटिफ़िकेशन क्षेत्र में चलता
  रहता है ताकि रिकॉर्डिंग जारी रहे। फिर से खोलने के लिए ट्रे आइकन इस्तेमाल करें।
- **बंद करना स्पष्ट कार्रवाई है।** ट्रे आइकन पर राइट-क्लिक करें और **Quit
  Pandu** चुनें। बंद करने के बाद दोबारा शुरू करने तक एजेंट्स रिकॉर्ड नहीं होंगे।
- **आपका डेटा** `%USERPROFILE%\.pandu` में रहता है। डेटाबेस
  `%USERPROFILE%\.pandu\v2\pandu.db` है; सेटिंग्स, स्नैपशॉट और बैकअप उसी ट्री
  में हैं।

### अनइंस्टॉल

1. ट्रे से Pandu बंद करें।
2. **Settings > Apps > Installed apps** खोलें, **Pandu** खोजें और
   **Uninstall** चुनें।
3. अनइंस्टॉलर पूछता है कि `%USERPROFILE%\.pandu` हटाना है या नहीं। डिफ़ॉल्ट
   **No** है। अपनी फ़्लाइट्स, सेटिंग्स, स्नैपशॉट, बैकअप और जोड़े गए डिवाइस
   रखने के लिए **No** चुनें। स्थायी रूप से हटाने के लिए ही **Yes** चुनें।

पूरा विवरण [`uninstall.md`](uninstall.md) में है।

## Android कंपेनियन

कंपेनियन आपके फ़ोन के लिए एक छोटा, सीमित डैशबोर्ड है। यह फ़्लाइट्स देख सकता है
और अनुमोदन अनुरोधों का जवाब दे सकता है, लेकिन एजेंट शुरू नहीं कर सकता और
सेटिंग्स नहीं बदल सकता। यह वैकल्पिक है।

**प्रयोगात्मक:** Android कंपेनियन को एमुलेटर पर सत्यापित किया गया है, लेकिन
अभी किसी वास्तविक फ़ोन पर नहीं। जब तक फ़ोन सत्यापन दर्ज नहीं होता, APK रिलीज़
के साथ नहीं जोड़ा जाता; परखना चाहें तो इसे स्रोत से बनाएँ।

संक्षिप्त संस्करण:

1. कंप्यूटर पर **Settings > Remote access** खोलें और रिमोट एक्सेस चालू करें।
   Tailscale मोड चुनें और Pandu जो `tailscale serve` कमांड दिखाए उसे चलाएँ।
2. स्रोत से APK बनाएँ (प्रयोगात्मक); देखें [`android.md`](android.md)।
3. ब्राउज़र या फ़ाइल मैनेजर को अज्ञात ऐप्स इंस्टॉल करने की अनुमति दें, फिर
   APK खोलें।
4. फ़ोन पर Pandu खोलें और कंप्यूटर पर दिख रहा पेयरिंग QR कोड स्कैन करें।
5. कंप्यूटर पर डिवाइस को अनुमोदित करें। नए डिवाइस केवल **Status** से शुरू होते
   हैं।

पूरी गाइड, जिसमें अनुमतियाँ, बैटरी सेटिंग्स, नोटिफ़िकेशन चैनल और `apksigner`
सत्यापन शामिल हैं, [`android.md`](android.md) में है।

## इंस्टॉल करने योग्य वेब ऐप (PWA)

PWA वही रिमोट डैशबोर्ड है, जो ब्राउज़र से इंस्टॉल होता है। इसके लिए आपके
कंप्यूटर तक पहुँचने वाला HTTPS URL चाहिए, आमतौर पर `tailscale serve` से।

1. कंप्यूटर पर रिमोट एक्सेस चालू करें और `tailscale serve` शुरू करें।
2. अपने फ़ोन या किसी अन्य कंप्यूटर पर HTTPS URL खोलें।
3. ब्राउज़र मेन्यू से **Install app** या **Add to Home Screen** चुनें।
4. कंप्यूटर पर दिख रहे कोड से डिवाइस पेयर करें।

पूरी गाइड, जिसमें कैशिंग नियम और सीमाएँ शामिल हैं, [`pwa.md`](pwa.md) में है।

## कमांड-लाइन टूल

`pandu` CLI डेस्कटॉप ऐप से अलग है। इसे तब इंस्टॉल करें जब आप खुद डेमॉन चलाना,
`pandu run -- <agent>` इस्तेमाल करना, या डायग्नोस्टिक्स चलाना चाहते हों।

1. `pandu-cli-x86_64-pc-windows-msvc.zip` और `SHA256SUMS` डाउनलोड करें।
2. ऊपर दिखाए अनुसार `Get-FileHash` से आर्काइव जाँचें।
3. एक्सट्रैक्ट करें। `pandu.exe` आर्काइव के मूल में है।
4. एक्सट्रैक्शन फ़ोल्डर को `PATH` में जोड़ें, या `pandu.exe` को पूरे पथ से चलाएँ।

रिलीज़ में `pandu-cli-installer.ps1` भी है, जो वर्तमान उपयोगकर्ता के लिए CLI
इंस्टॉल करता है। अगर आप जानना चाहते हैं कि यह ठीक कहाँ लिखता है, तो स्क्रिप्ट
चलाने से पहले पढ़ें।

पहले के उपयोगी कमांड:

```powershell
pandu doctor
pandu serve
pandu pair
```

`pandu doctor` डेटाबेस, एडाप्टर, लॉग वॉचर और चल रहे डेमॉन की जाँच करता है। यह
केवल स्थानीय जानकारी छापता है। `pandu pair` एक अल्पकालिक पेयरिंग कोड और फ़ोन
पर इस्तेमाल करने का रिमोट URL छापता है।

## समस्या हल करना

अगर कुछ काम न करे, तो [`troubleshooting.md`](troubleshooting.md) पढ़ें। इसमें
SmartScreen, WebView2, पोर्ट टकराव, फ़ायरवॉल प्रॉम्प्ट, पेयरिंग विफलता,
नोटिफ़िकेशन समस्याएँ, और डेटा खोए बिना Pandu रीसेट करने का तरीका है।

## एक पैराग्राफ में गोपनीयता

Pandu स्थानीय रूप से रिकॉर्ड करता है। डेस्कटॉप ऐप केवल लूपबैक पर डेमॉन से बात
करता है। रिमोट एक्सेस डिफ़ॉल्ट रूप से बंद है और केवल कंप्यूटर से चालू किया जा
सकता है। अपडेट जाँच GitHub पर अधिकतम हर 24 घंटे में एक HTTPS अनुरोध है और इसे
बंद किया जा सकता है। कोई टेलीमेट्री, क्लाउड सिंक या पृष्ठभूमि अपलोड नहीं है।
पूरा बयान [`privacy.md`](../privacy.md) में है।
