# Deferred feature issue drafts

These are ready-to-paste GitHub issues for features that are intentionally not
part of v0.2.0. Each one is labeled `help wanted` and includes a spec,
acceptance criteria, non-goals, and a starting point.

| Draft | Area | Size |
| --- | --- | --- |
| [Arena](arena.md) | Compare agent runs | L |
| [Journal](journal.md) | Local daily log | M |
| [Plugins](plugins.md) | Sandboxed extensions | XL |
| [Project Brain](project-brain.md) | Local repo memory | L |
| [Handoff](handoff.md) | Baton pass between sessions | M |
| [Understanding Debt](understanding-debt.md) | Optional comprehension checks | L |
| [Context Doctor](context-doctor.md) | Context composition analysis | M |
| [Provenance](provenance.md) | Change-to-prompt attribution | L |

To publish one, copy its contents into a new GitHub issue and apply the labels
listed at the top. Do not add them to the v0.2.0 milestone.
